TECHNICAL HIGHLIGHTS
技术要点
03
状态机管理

页面采用 state 变量管理不同交互阶段（card → subway → phone → sub）的切换逻辑，防止重复触发。

碎屏转场

通过将画面分割为 22 个外扇形 + 8 个内小三角形多边形碎片，叠加旋转飞散动画，配合冲击点燃烧核心。

视频无缝循环

视频首帧与尾帧像素差异极小时可实现原生无缝循环；通过 Lanczos 放大、锐化和高码率提升清晰度。

手指模型修复

原 SVG 使用 preserveAspectRatio="none" 会导致手指被拉伸变形，改用 CSS 独立绘制手指形状避免拉伸。

UI 倾斜对齐

手机屏幕为倾斜状态，通过 transform-origin + rotate(8.55deg) 让 UI 层与屏幕角度精确匹配。

逐帧动画

使用多层 img 叠加切换显隐的方式避免视频解码闪烁问题；动画与容器升起位移同步实现转动视觉效果。

底边对齐

transform-origin 设为底边可确保动画过程中底部位置稳定；移除摇摆动画中的 translateY 避免周期性上浮。

实时时钟

手机状态栏、主屏角标、主屏时钟与电脑系统实时时间同步更新，每秒刷新一次。
